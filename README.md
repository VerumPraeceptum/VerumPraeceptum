# VerumPraeceptum

I build game systems for Roblox. Most of what I write is designed to be dropped into a project with minimal setup and stay out of the way.

## Open Source Projects

### Denabled
A lightweight system loader for Roblox. You point it at a folder, it requires everything inside, and runs each system through a controlled lifecycle: Init, PostInit, then Start. Each phase waits for the previous one to finish before moving on.

### VerProfile
A player data system built on top of ProfileStore and ReplicaService. It handles loading, saving, and replicating player data to the client using a typed schema you define once.
